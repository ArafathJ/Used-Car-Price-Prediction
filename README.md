# Used-Car-Price-Prediction

This project involves building a machine learning model to predict the selling price of used cars based on various features such as brand, model, year, mileage, engine, fuel type, transmission, and ownership history.

Key Highlights:

  - Data preprocessing and cleaning(handling missing values, encoding categorical features, scaling numerical features)
  - Feature selection using SelectKBest with f_regression
  - Model building and evaluation using:
      -Linear Regression
      -Decision Tree Regressor
      -Random forest Regressor
  - Performance comparison using cross-validation
  - Final model selection based on R² score and MAE
  - Model deployment preparation: trained pipeline saved using joblib

Technologies Used:
  -Python
  -Pandas, Numpy
  -scikit-learn
  -Jupyter Notebook

The final trained model is ready to be integrated into a web application for real-time used car price predictions.
